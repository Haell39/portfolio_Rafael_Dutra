# Rafael Dutra Portfolio

Portfólio profissional de Rafael Dutra, posicionado como **Analista de Dados | Analytics Engineer**, com foco em SQL, Power BI, Python, Excel, PostgreSQL e qualidade de dados.

## Stack

- React 18
- Vite
- Framer Motion
- Lucide React
- CSS responsivo com temas claro e escuro

## Execução

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

## Estrutura de conteúdo

- `src/i18n/translations.js`: copy em português, inglês e espanhol.
- `src/content/portfolioData.js`: projetos e certificados.
- `docs/cases_profissionais.md`: fonte interna dos cases profissionais.
- `src/styles/variables.css`: tokens do design system.
- `src/styles/components.css`: layout e responsividade das seções.

## Cases profissionais

- Reconhecimento facial integrado ao fluxo de acesso: em produção.
- Ingestão e roteamento de dados educacionais: homologado.
- IA multimodal para avaliações e relatórios pedagógicos: homologado, com prompts, contratos JSON, seis templates de relatórios 360 e 39 testes locais aprovados na validação inicial com dados fictícios. Destaques: NLP com LLMs e Prompt Engineering.

O terceiro card tem detalhes expansíveis sobre problema, contribuição, decisões técnicas, validação e estágio da entrega. O conteúdo é mantido em português, inglês e espanhol em `src/i18n/translations.js`.
